# Juniors Barber Parlor

Website for Junior's Barber Parlor in Midtown Phoenix, built with React and [Vite](https://vite.dev/).

## Scripts

- `npm run dev` (or `npm start`) — start the dev server at http://localhost:5173
- `npm run build` — build the production site into `build/`
- `npm run preview` — serve the production build locally
